Post-Migration Cost Optimization and Governance Plan
Moving to the cloud is only half the job. Without good rules, cloud bills can quickly grow out of control. Here is the 4-step plan Ace Medicare Clinics will follow after moving to Azure to keep costs low and stay HIPAA and NDPR compliant:
Step 1: Lock In Big Discounts Right Away (Days 1 to 30)
•	Use Azure Hybrid Benefit: Apply the Windows Server and SQL licenses the hospital already owns to our new Azure servers so we do not pay for licenses twice.
•	Buy Reserved Instances (RIs): Since our main patient database and EHR system run 24/7 all year, we will commit to a 3-year plan with Microsoft in exchange for up to 45% off regular hourly rates.
Step 2: Stop Paying for Unused Resources (Days 30 to 60)
•	Right-Size Oversized Servers: After 30 days, check Azure Advisor. If a server is only using 15% of its power, shrink it to a smaller, cheaper size.
•	Auto-Shutdown Test Servers: Set all testing and training servers to automatically turn off every night at 7:00 PM and on weekends when IT staff go home.
•	Move Old X-Rays to Archive Storage: Automatically move X-ray and MRI files older than 1 year into Azure Archive Storage, which costs a fraction of a cent per gigabyte while still keeping files for the required 7 years.
Step 3: Set Guardrails So Nobody Breaks the Rules (Days 60 to 90)
•	Manage On-Site Machines with Azure Arc: Connect any remaining local hospital servers to Azure Arc so the IT team can monitor security and updates for both local and cloud computers on one screen.
•	Use Azure Policy and Resource Tags: Require every new resource to have a label (Department, Owner, Environment) so we always know which hospital department is spending money. Also, block staff from creating unencrypted storage or super-expensive server sizes by accident.
Step 4: Monthly Budget Checks (Ongoing)
•	Set Spending Alerts: Use Microsoft Cost Management to send automatic emails to the IT manager whenever monthly spending hits 75%, 90%, and 100% of our budget so there are never any surprise bills.
